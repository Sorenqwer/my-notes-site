Co-offending games (coordination and betrayal)

What it is

Co-offending can be modeled as a coordination/trust problem: - group action increases returns or reduces risk, - but creates betrayal and coordination failure risks.

Canonical stag-hunt setup

Two agents choose Join (\(J\)) or Stay out (\(O\)).

  • If both join: \((J,J)\) yields \(G>0\) each.
  • If one joins alone: joiner gets \(-d<0\), other gets \(0\).
  • If both stay out: \((0,0)\).

Equilibria

Two pure Nash equilibria: - \((J,J)\) (high-participation) - \((O,O)\) (low-participation)

Interpretation: co-offending can be self-reinforcing; small shifts in risk/coordination can change equilibrium selection.
