Information & beliefs (measure-lite)

What “information” means in game theory

In Bayesian and information economics, “information” is usually represented by what events a player can distinguish.

There are two common (equivalent) ways to think about it:

  • Information partition (finite case): a player observes which cell of a partition they are in.
  • \(\sigma\)-algebra (general case): the collection of events the player can condition on.

You almost never need heavy measure theory for standard game theory notes—just the intuition.

\(\sigma\)-algebra (concept only)

Let \(\Omega\) be the set of possible states of the world.
A \(\sigma\)-algebra \(\mathcal{F}\) is a collection of subsets of \(\Omega\) (events) such that:

  1. \(\Omega \in \mathcal{F}\)
  2. If \(A \in \mathcal{F}\) then \(A^c \in \mathcal{F}\)
  3. If \(A_1, A_2, \dots \in \mathcal{F}\) then \(\bigcup_{k=1}^\infty A_k \in \mathcal{F}\)

Intuition. \(\mathcal{F}\) lists the events you are able to talk about (and condition on).
Coarser \(\mathcal{F}\) = less information.

Finite shortcut (partition view)

If \(\Omega\) is finite and a player’s information is a partition \[ \Pi = \{C_1,\dots,C_m\}, \] then the player can distinguish only which cell \(C_j\) contains the true state.
The corresponding \(\sigma\)-algebra is “all unions of cells of \(\Pi\)”.

Conditional expectation as “best prediction given information”

Given an integrable random variable \(X\) (e.g., payoff-relevant quantity) and an information set \(\mathcal{G}\subseteq\mathcal{F}\), the conditional expectation \(\mathbb{E}[X\mid \mathcal{G}]\) is the random variable that represents the best mean-squared prediction of \(X\) using only information in \(\mathcal{G}\).

Projection idea (intuition). Think of \(\mathbb{E}[X\mid \mathcal{G}]\) as projecting \(X\) onto the space of \(\mathcal{G}\)-measurable variables (things you can compute using the information you have).

Example: conditional expectation with a partition

Let the state space be \[ \Omega=\{\omega_1,\omega_2,\omega_3,\omega_4\}, \qquad \mathbb{P}(\omega_k)=\tfrac14 \text{ for each }k. \]

Let \[ X(\omega_1)=0,\;X(\omega_2)=2,\;X(\omega_3)=4,\;X(\omega_4)=6. \]

Suppose the player only observes whether the state is in \[ C_1=\{\omega_1,\omega_2\}\quad\text{or}\quad C_2=\{\omega_3,\omega_4\}. \]

That information corresponds to a partition \(\Pi=\{C_1,C_2\}\) (and a \(\sigma\)-algebra generated by it).

Then the conditional expectation is constant on each cell:

  • On \(C_1\): \[ \mathbb{E}[X\mid C_1] =\frac{X(\omega_1)+X(\omega_2)}{2} =\frac{0+2}{2}=1. \]

  • On \(C_2\): \[ \mathbb{E}[X\mid C_2] =\frac{X(\omega_3)+X(\omega_4)}{2} =\frac{4+6}{2}=5. \]

So \(\mathbb{E}[X\mid \mathcal{G}]\) takes value \(1\) if you learn “cell \(C_1\)”, and value \(5\) if you learn “cell \(C_2\)”.

Game theory interpretation. This is exactly what beliefs do: you map what you observed to an updated expectation of payoff-relevant quantities.

Common knowledge (concept)

An event \(E\) is common knowledge if: - everyone knows \(E\), - everyone knows that everyone knows \(E\), - everyone knows that everyone knows that everyone knows \(E\), - and so on indefinitely.

Intuition. Common knowledge is what makes coordination possible (or impossible). It is stronger than “everyone knows”.

Iterated beliefs (one-line idea)

In Bayesian games, strategies can depend on: - beliefs about types, - beliefs about others’ beliefs, - higher-order beliefs.

Often you don’t compute these explicitly; you just need to know they exist and that equilibrium concepts impose consistency.

Practical takeaway

For most game theory work: - partitions are enough to model information, - conditional expectation captures “best prediction given what you know”, - common knowledge / higher-order beliefs matter conceptually for coordination and equilibrium.
