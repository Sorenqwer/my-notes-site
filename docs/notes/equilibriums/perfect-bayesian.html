Perfect Bayesian Equilibrium

Perfect Bayesian equilibrium is a solution concept for dynamic games with incomplete information. It combines sequential rationality with beliefs.

The central idea is:

players should act optimally at every point, given their beliefs, and beliefs should be updated consistently whenever possible.

Perfect Bayesian equilibrium is especially important for signaling games, cheap-talk games, reputation models, and dynamic Bayesian games.

Why PBE is needed

Bayesian Nash equilibrium handles incomplete information, but it is not enough for dynamic games where players observe actions and update beliefs over time.

Subgame perfect equilibrium handles dynamic games, but it may not fully discipline beliefs after observed actions.

Perfect Bayesian equilibrium combines both concerns.

Main components

A perfect Bayesian equilibrium includes:

  1. strategies for all players;
  2. beliefs at information sets;
  3. sequential rationality;
  4. belief consistency using Bayes’ rule wherever possible.

Strategies say what players do.
Beliefs say what players think has happened or what type they face.

Sequential rationality

Sequential rationality means that at every information set, each player’s strategy must be optimal given their belief and the continuation strategies.

In words:

whenever a player is called to move, the prescribed action must maximize expected payoff from that point onward.

This requirement applies both on and off the equilibrium path.

Beliefs

Beliefs describe the probability a player assigns to possible nodes, states, or types at an information set.

For example, after observing message \(m\), a receiver may believe:

\[ \mu(H\mid m)=0.7. \]

This means the receiver assigns probability 0.7 to the sender being high type after observing message \(m\).

The receiver then chooses an action that maximizes expected payoff under this belief.

Bayes’ rule on path

If an information set is reached with positive probability in equilibrium, beliefs must be updated by Bayes’ rule.

For a message \(m\):

\[ \mu(\theta\mid m) = \frac{ \Pr(m\mid \theta)\Pr(\theta) }{ \sum_{\theta'}\Pr(m\mid \theta')\Pr(\theta') }. \]

Off-path beliefs

If an information set is reached with zero probability in equilibrium, Bayes’ rule may not pin down beliefs.

These are off-path beliefs.

PBE allows some freedom in off-path beliefs, but the beliefs still influence whether the equilibrium is plausible.

This is one reason sequential equilibrium is sometimes preferred: it imposes stronger consistency requirements.

PBE in signaling games

In a signaling game, a PBE specifies:

  1. sender signal choice for each type;
  2. receiver belief after each signal;
  3. receiver action after each signal;
  4. optimality for sender and receiver;
  5. Bayes-consistent beliefs on path.

A separating PBE has different types sending different signals.
A pooling PBE has different types sending the same signal.

Separating PBE

In a separating PBE:

\[ s(H) \neq s(L). \]

The receiver can infer type from signal.

For example:

\[ \mu(H\mid s_H)=1, \]

and

\[ \mu(L\mid s_L)=1. \]

The sender types must prefer their assigned signals, and the receiver must best respond to the inferred type.

Pooling PBE

In a pooling PBE:

\[ s(H)=s(L). \]

Both types send the same signal.

The receiver cannot infer the type from the pooled signal and uses the prior belief after observing it.

Off-path beliefs after unexpected signals can be important for sustaining the pooling equilibrium.

Cheap talk and PBE

Cheap-talk games are often solved using PBE.

A cheap-talk PBE requires:

  • sender messages are optimal given expected receiver responses;
  • receiver actions are optimal given beliefs after messages;
  • beliefs are updated by Bayes’ rule when possible.

Babbling equilibria are PBE in many cheap-talk games.

PBE versus SPE

Concept Used for Main requirement
SPE dynamic complete-information games Nash equilibrium in every subgame
PBE dynamic incomplete-information games sequential rationality plus beliefs
Sequential equilibrium dynamic incomplete-information games stronger belief consistency

PBE is more general than SPE for games where beliefs matter.

Common mistakes

1. Giving strategies but no beliefs

A PBE requires both strategies and beliefs.

2. Checking only on-path optimality

Sequential rationality must hold at every information set.

3. Ignoring Bayes’ rule

On-path beliefs must be consistent with Bayes’ rule.

4. Treating off-path beliefs as irrelevant

Off-path beliefs can support or destroy candidate equilibria.

5. Using BNE when actions reveal information over time

Dynamic updating usually requires PBE or sequential equilibrium.

Checklist

When checking PBE, ask:

  1. What are the players and types?
  2. What are the histories and information sets?
  3. What strategy is assigned to each player or type?
  4. What beliefs are assigned at each information set?
  5. Are beliefs on path derived by Bayes’ rule?
  6. Is each player sequentially rational given beliefs?
  7. Are sender incentive constraints satisfied?
  8. Are receiver responses optimal?
  9. What happens after off-path actions?
  10. Is a stronger refinement needed?
