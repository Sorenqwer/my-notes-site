Bayesian Nash Equilibrium

Bayesian Nash equilibrium is the basic equilibrium concept for static games with incomplete information. It requires every type of every player to choose a best response, given beliefs about other players’ types and strategies.

The central idea is:

each possible type must be optimizing under uncertainty.

From Nash to Bayesian Nash

In a complete-information game, Nash equilibrium requires each player to best respond to others’ strategies.

In a Bayesian game, each player may have different possible types. Therefore, equilibrium must specify what each type does.

The difference is that strategies are type-contingent.

Basic setup

A Bayesian game includes:

Object Meaning
\(N\) players
\(\Theta_i\) type space of player \(i\)
\(A_i\) action set of player \(i\)
\(p(\theta)\) prior over type profiles
\(u_i(a,\theta)\) payoff of player \(i\)

A strategy for player \(i\) is a function:

\[ s_i:\Theta_i \to A_i. \]

This means that the strategy assigns an action to every type.

Expected payoff

If player \(i\) has type \(\theta_i\), then the player forms beliefs about other players’ types \(\theta_{-i}\).

Given a strategy profile \(s\), the expected payoff from choosing action \(a_i\) is:

\[ \sum_{\theta_{-i}} u_i(a_i,s_{-i}(\theta_{-i}),\theta_i,\theta_{-i}) \Pr(\theta_{-i}\mid \theta_i). \]

The type \(\theta_i\) chooses the action that maximizes this expected payoff.

Definition

A strategy profile

\[ s^*=(s_1^*,\ldots,s_n^*) \]

is a Bayesian Nash equilibrium if, for every player \(i\) and every type \(\theta_i \in \Theta_i\),

\[ s_i^*(\theta_i) \in \arg\max_{a_i\in A_i} \sum_{\theta_{-i}} u_i(a_i,s_{-i}^*(\theta_{-i}),\theta_i,\theta_{-i}) \Pr(\theta_{-i}\mid \theta_i). \]

In words:

each type chooses a best response to the type-contingent strategies of others.

The logic

This is the core of Bayesian Nash equilibrium.

Example: two types

Suppose player 1 can be type \(H\) or type \(L\).

A strategy for player 1 is not just one action. It must specify:

\[ s_1(H) \]

and

\[ s_1(L). \]

For example:

\[ s_1(H)=A, \qquad s_1(L)=B. \]

This means the high type chooses \(A\), while the low type chooses \(B\).

The opponent may not observe the type, but forms beliefs about which type is being faced.

Type-contingent best response

Suppose type \(H\) and type \(L\) have different payoffs.

Then the same action may be optimal for one type but not for the other.

Bayesian Nash equilibrium requires both type-specific choices to be optimal.

Pure and mixed Bayesian strategies

A pure Bayesian strategy maps each type to a pure action.

A mixed Bayesian strategy maps each type to a probability distribution over actions.

For example:

\[ \sigma_i(\theta_i)(a_i) \]

is the probability that type \(\theta_i\) of player \(i\) chooses action \(a_i\).

This allows different types to randomize differently.

Interim perspective

Bayesian Nash equilibrium is usually defined from the interim perspective.

This means each player has already learned their own type but remains uncertain about others’ types.

The stages are:

BNE asks whether each type is optimal at the interim stage.

Bayesian Nash and Bayes’ rule

In static Bayesian games, beliefs are usually derived from the common prior and the player’s own type.

If types are independent, then learning your own type may not change beliefs about others.

If types are correlated, then learning your own type may provide information about others.

Bayes’ rule gives:

\[ \Pr(\theta_{-i}\mid \theta_i) = \frac{ \Pr(\theta_i,\theta_{-i}) }{ \Pr(\theta_i) }. \]

This conditional belief is used in the expected payoff calculation.

Relation to Harsanyi transformation

Bayesian Nash equilibrium can be understood as Nash equilibrium in the Harsanyi-transformed game.

The transformed game has:

  1. nature draws types;
  2. each player observes own type;
  3. each player chooses an action according to a type-contingent strategy.

This is why Bayesian Nash equilibrium is a natural extension of Nash equilibrium.

Example structure: first-price auction

In a first-price sealed-bid auction, each bidder knows their own valuation but not others’ valuations.

A bidder’s type is their valuation:

\[ \theta_i = v_i. \]

A strategy maps valuation into bid:

\[ b_i(v_i). \]

A Bayesian Nash equilibrium is a bidding function where every valuation type bids optimally given beliefs about other bidders’ valuations and bidding strategies.

This shows why BNE is useful in auctions.

Example structure: entry with unknown cost

Suppose a firm may be high-cost or low-cost. A rival does not observe the cost type.

The firm’s strategy specifies what each cost type does:

\[ s(H), \quad s(L). \]

The rival’s strategy is based on expected payoff under beliefs about whether the firm is high-cost or low-cost.

The equilibrium requires:

  • high-cost type best responds;
  • low-cost type best responds;
  • rival best responds to its beliefs.

BNE versus PBE

Bayesian Nash equilibrium is mainly for static incomplete-information games.

Perfect Bayesian equilibrium is for dynamic incomplete-information games.

Concept Used for Requires
Bayesian Nash equilibrium static incomplete information type-contingent best responses
Perfect Bayesian equilibrium dynamic incomplete information sequential rationality and beliefs
Sequential equilibrium dynamic incomplete information stronger belief consistency

If actions reveal information over time, BNE may not be enough.

Common mistakes

1. Solving only for one type

Every possible type must be optimizing.

2. Forgetting that strategy is a function

A Bayesian strategy maps types to actions.

3. Confusing type and belief

A type is private information. A belief is a probability over unknown types or states.

4. Ignoring expected payoff

Players choose based on expected payoff over uncertain types.

5. Applying BNE to dynamic signaling without beliefs after actions

Dynamic signaling games usually need PBE or sequential equilibrium.

6. Forgetting type correlation

If types are correlated, observing your own type can change beliefs about others.

Checklist

When checking Bayesian Nash equilibrium, ask:

  1. What are the players?
  2. What are the type spaces?
  3. What does each player observe?
  4. What is the prior distribution?
  5. Are types independent or correlated?
  6. What is each player’s action set?
  7. What is each type’s strategy?
  8. What belief does each type hold about others?
  9. What expected payoff does each type maximize?
  10. Is every type choosing a best response?
