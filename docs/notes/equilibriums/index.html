Equilibrium Concepts

Equilibrium concepts describe what it means for behaviour to be stable in a strategic setting. Different games require different notions of stability: simultaneous games need mutual best responses; dynamic games need credible continuation behaviour; incomplete-information games need beliefs; and communication games need consistency between messages, beliefs, and incentives.

The purpose of this page is to give a map of the main equilibrium concepts used across the notes.

The basic question

Every equilibrium concept answers some version of the same question:

Given what everyone else is doing, believing, or expecting, does each player have a reason to change their behaviour?

The details depend on the model. In a static game, the issue is whether anyone wants to deviate from their chosen action. In a dynamic game, we also ask whether future threats and promises are credible. In a Bayesian game, we ask whether each type of each player is acting optimally given beliefs.

A map of equilibrium concepts

The map is not a strict hierarchy. Some concepts are designed for different kinds of games, while others are refinements that rule out implausible equilibria.

Core equilibrium concepts

Nash Equilibrium

The basic equilibrium concept for strategic interaction. Each player chooses a best response to the strategies of the others.

Refinements and related notions

Trembling-hand Perfect Equilibrium

Rules out equilibria that are not robust to small mistakes.

Proper Equilibrium

A stronger refinement where more costly mistakes are much less likely than less costly mistakes.

Rationalizability

Keeps strategies that can survive iterative best-response reasoning, without requiring a full equilibrium.

From basic equilibrium to refinements

A useful way to understand refinements is to ask what problem each concept tries to fix.

Nash equilibrium is the starting point. Refinements add extra discipline when the basic idea of mutual best response is not enough.

Choosing the right concept

This decision tree is only a guide. In actual modelling, the right solution concept depends on what the model needs to explain.

Why equilibrium is not enough

An equilibrium can be stable but undesirable. It can also be mathematically valid but behaviourally implausible. This is why equilibrium analysis usually needs interpretation.

When reading an equilibrium result, ask:

  1. What incentives make this behaviour stable?
  2. What beliefs support the behaviour?
  3. Are threats and promises credible?
  4. Is the equilibrium efficient or inefficient?
  5. Are there multiple equilibria?
  6. Would the result survive small changes in assumptions?

These questions matter because equilibrium is a tool for explanation, not a guarantee of realism.
