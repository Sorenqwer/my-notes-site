Cheap Talk

Cheap talk is communication that is costless, non-binding, and directly payoff-irrelevant. A sender sends a message, and a receiver chooses an action after hearing it.

The central question is:

Can information be transmitted when messages are free and interests are not perfectly aligned?

Cheap talk is important because many real interactions involve advice, promises, claims, warnings, recommendations, excuses, and persuasion without formal commitment.

Basic structure

A cheap-talk game usually has three stages:

  1. Nature determines the sender’s private information.
  2. The sender sends a costless message.
  3. The receiver observes the message and chooses an action.

The message has no direct payoff effect. It matters only if it changes the receiver’s belief and action.

Why cheap talk is puzzling

If messages are free, why would anyone believe them?

A sender may want to manipulate the receiver. If the receiver knows this, the receiver may ignore the message. If messages are ignored, communication becomes uninformative.

This creates the basic cheap-talk tension:

Cheap talk is therefore not automatically informative.

Sender and receiver

The sender has information. The receiver has decision power.

For example:

  • an expert advises a policymaker;
  • a seller describes product quality;
  • a suspect gives an explanation;
  • a doctor recommends treatment;
  • a friend gives advice;
  • a manager reports project progress;
  • a lobbyist communicates with a regulator.

Cheap talk appears whenever one side knows something and the other side must decide how much to trust the message.

Messages

Messages are often written as:

\[ m \in M. \]

A sender’s strategy maps information into messages.

If the sender observes state \(\theta\), a messaging strategy is:

\[ \sigma_S(\theta) \in M. \]

The receiver’s strategy maps messages into actions:

\[ \sigma_R(m) \in A. \]

A cheap-talk equilibrium specifies both a sender messaging rule and a receiver response rule.

Beliefs

After hearing message \(m\), the receiver forms a belief about the state:

\[ \mu(\theta \mid m). \]

If message \(m\) is sent with positive probability in equilibrium, beliefs are updated using Bayes’ rule:

\[ \mu(\theta \mid m) = \frac{ \Pr(m\mid \theta)\Pr(\theta) }{ \sum_{\theta'}\Pr(m\mid \theta')\Pr(\theta') }. \]

The receiver then chooses an action that maximizes expected payoff given this posterior belief.

Informative and uninformative communication

Cheap talk may be:

Type Meaning
Fully revealing different states induce different messages
Partially revealing messages reveal coarse information
Babbling messages reveal no information
Pooling multiple types send the same message
Separating different types send different messages

A babbling equilibrium always exists in many cheap-talk games: the sender’s message is ignored, so the sender has no reason to choose one message over another.

Babbling equilibrium

In a babbling equilibrium:

  1. all types of sender send messages that do not affect beliefs;
  2. the receiver ignores the message;
  3. the receiver chooses the action optimal under the prior.

Babbling is uninformative communication. It is strategically stable because messages do not change the receiver’s action.

When can cheap talk be informative?

Cheap talk can be informative when sender and receiver interests are sufficiently aligned.

If the sender benefits when the receiver chooses an action close to the truth, then the sender may have an incentive to communicate honestly or partially honestly.

If the sender always wants the receiver to choose a higher action than the receiver would prefer, full truth-telling may fail, but coarse communication may still be possible.

The degree of conflict shapes how much information can be transmitted.

Bias

A common cheap-talk model has a sender who is biased relative to the receiver.

For example, the receiver wants to choose action \(a\) close to state \(\theta\):

\[ u_R(a,\theta)=-(a-\theta)^2. \]

The sender wants the receiver’s action to be shifted upward by bias \(b\):

\[ u_S(a,\theta)=-(a-(\theta+b))^2. \]

If \(b=0\), preferences are aligned.
If \(b>0\), the sender wants a higher action than the receiver would choose under full information.

The larger the bias, the harder informative communication becomes.

Partition equilibria

In some cheap-talk games, equilibrium communication partitions the state space.

The sender does not reveal the exact state. Instead, the sender sends a message indicating that the state lies in a range.

This is partial information transmission.

Cheap talk and deception

Cheap talk is useful for thinking about deception because messages can move beliefs without being costly or binding.

However, deception is not always simply “lying.” A sender may:

  • reveal fully;
  • pool with other types;
  • exaggerate;
  • understate;
  • send vague messages;
  • stay silent;
  • use ambiguity strategically.

The receiver’s interpretation depends on equilibrium beliefs.

Cheap talk versus signaling

Cheap talk differs from signaling.

Feature Cheap talk Signaling
Message/action cost costless often costly
Direct payoff effect none may affect payoffs directly
Information source strategic message costly action or signal
Credibility from incentives and equilibrium often from differential costs

Cheap talk can be credible only through aligned incentives or equilibrium structure. Signaling can be credible because different types face different costs or benefits from sending signals.

Common mistakes

1. Assuming costless messages are always meaningless

Cheap talk can be informative when incentives are sufficiently aligned.

2. Assuming messages are automatically truthful

Cheap talk requires incentive compatibility. Truthful messages must be optimal for the sender.

3. Ignoring receiver beliefs

Messages matter only through beliefs and receiver actions.

4. Confusing babbling with no communication

Babbling may involve messages, but messages carry no information.

5. Treating off-path beliefs as irrelevant

Unexpected messages may affect whether a proposed equilibrium is plausible.

Checklist

When analysing a cheap-talk game, ask:

  1. What does the sender know?
  2. What does the receiver need to decide?
  3. What messages are available?
  4. Are messages costly or binding?
  5. What are the sender’s preferences?
  6. What are the receiver’s preferences?
  7. Are preferences aligned or biased?
  8. How does each message change beliefs?
  9. What is the receiver’s best response to each belief?
  10. Is the sender willing to send the proposed message?
